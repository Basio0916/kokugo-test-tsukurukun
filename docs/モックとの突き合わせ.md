# モックとの突き合わせ

`docs/reference/モック.html` の機能を一つずつ、今の実装と突き合わせた表。状態は次の三つ。

- 作った: 実装した。仕様（`openspec/specs/`）か PR を書く
- 意図的に違う: ユーザーか context が違う形を決めた。出どころを書く
- 未対応: まだ作っていない。作る change を書く

モックで「本番では AI が…」と書かれているもの（モックでは表示だけのもの）は、「context の要件」として分けて書く。
