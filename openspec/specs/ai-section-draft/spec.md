# ai-section-draft Specification

## Purpose

文章を扱う大問の小問を AI に作ってもらい、返答を検証・変換して紙面に出す。AI は中身だけを返し、傍線部の位置・番号・配点の割り振りはシステムが決める。

## Requirements

### Requirement: 大問を AI に作ってもらえる
文章を扱う大問で「AI に大問を作ってもらう」を選ぶと、その大問の本文、種類、指示文、単元の指導事項（単元データから引いたもの）、学年、大問の小計を AI に渡し、AI が作った小問の並びでその大問の小問を置き換える SHALL。本文、指示文、他の大問は変えない。

#### Scenario: 走れメロスの大問を作ってもらう
- **WHEN** サンプルのテストで、走れメロスの大問の「AI に大問を作ってもらう」を押し、AI が正しい返答を返す
- **THEN** 走れメロスの大問の小問が AI の作ったものに置き換わり、本文と他の大問はそのまま紙面に描かれる

### Requirement: 傍線部は本文からの引用で受け取り、システムが位置を決める
AI は傍線を引く箇所を、本文からそのまま引用した文字列で返す SHALL。システムは引用を本文（ルビの親文字をつないだ文字列）の中で探し、見つかった範囲に傍線部を付け、識別子を付ける。本文の文字は変えない。それまで本文に付いていた傍線部は外す。引用が本文に見つからない、または本文に二回以上現れて前後の文脈でも一つに決まらない場合、その返答は不正として扱う。引用の端がルビの親文字の途中にかかる場合も不正として扱う。

#### Scenario: 引用が本文に一つだけある
- **WHEN** AI が「メロスには政治がわからぬ」を引用し、その小問がこの傍線部を参照する
- **THEN** 本文の「メロスには政治がわからぬ」に傍線部が付き、問い文の参照は紙面で「傍線部①」のように本文の順の番号で描かれる

#### Scenario: 引用が本文にない
- **WHEN** AI が本文にない文字列（本文の文字を一字でも変えたもの）を引用する
- **THEN** その返答は不正として扱われ、紙面は変わらない（作り直しの対象になる）

### Requirement: 番号と配点はシステムが決める
AI の返答に、問の番号、傍線部の番号、選択肢の記号を含めない SHALL。問い文の中の傍線部への参照と選択肢の範囲は記法（`{傍線部:キー}`、`{範囲}`）で受け取り、番号や記号の文字（①、ア〜エ など）が問い文に含まれる返答は不正として扱う。配点は、AI が小問ごとに返す重みから、大問の小計を保ったまま、配点の刻みの倍数になるように割り振る。割り振りは同じ入力に対して常に同じ結果になる。

#### Scenario: 配点の割り振り
- **WHEN** 小計二十四点・刻み一点の大問で、AI が四つの小問に重み 1・1・2・1 を返す
- **THEN** 配点は合計がちょうど二十四点になり、どれも一点の倍数で、重みの大きい小問ほど配点が大きい（例: 5・5・9・5）

#### Scenario: 問い文に番号が書かれている
- **WHEN** AI の問い文に「傍線部①」や「ア〜エ」が文字で書かれている
- **THEN** その返答は不正として扱われる

### Requirement: 返答を検証し、通らなければ一度だけ作り直してもらう
AI の返答は、まず返答用の形で検証し、テストのデータに変換したうえで、テストのデータの検証（配点の刻み、選択肢と正答、解答形式ごとの必須の項目）にも通す SHALL。どこかで通らなければ、通らなかった理由を添えて AI に一度だけ作り直してもらう。作り直しても通らなければ、紙面を変えずに、作れなかったことを画面に知らせる。

#### Scenario: 二回とも通らない
- **WHEN** AI の返答が二回続けて検証に通らない
- **THEN** 紙面の大問は元のままで、画面に「作れませんでした」と理由が表示される

### Requirement: 作っている間と作った後の表示
作っている間は、その大問を作っていることを画面に表示し、同じ大問をもう一度作らせる操作はできない SHALL。作った後は、小問ごとに AI が示した提案の理由を、紙面の外（印刷されない場所）に一覧で示す。単元の指導事項にない記号の小問には、そのことを示す。

#### Scenario: 作っている間
- **WHEN** 「AI に大問を作ってもらう」を押した直後
- **THEN** 「作っています」の表示が出て、ボタンは押せなくなる

#### Scenario: 指導事項から外れる小問
- **WHEN** AI が作った小問の指導事項の記号が、単元データのその教材の指導事項にない
- **THEN** 理由の一覧で、その小問に「単元の指導事項にない」ことが示される

### Requirement: Claude の呼び出しはサーバー側で行う
Claude API の呼び出しはサーバー側の関数で行い、API キーはサーバーの環境変数だけに置く SHALL。ブラウザに送るコードと通信に API キーを含めない。手元の開発環境でも、デプロイした環境と同じ関数で動く。

#### Scenario: ブラウザに API キーがない
- **WHEN** ビルドしたブラウザ向けのファイルを調べる
- **THEN** API キーも、API キーを読む処理も含まれていない

### Requirement: デプロイした環境で動く
Vercel にデプロイした公開 URL で、サンプルのテストの表示と「AI に大問を作ってもらう」が手元と同じように動く SHALL。

#### Scenario: 公開 URL で大問を作る
- **WHEN** 公開 URL を開いて、走れメロスの大問を AI に作ってもらう
- **THEN** 手元と同じように、作られた小問が紙面に出る
