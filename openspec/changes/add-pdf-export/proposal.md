## Why

できあがったテストは、職員室で印刷したり、学年の先生に回したり、データで保管したりするので、紙ごとの PDF ファイルとして手元に残せる必要がある。いまはブラウザの印刷を自分で開くしかなく、ファイル名も決まらない。また、採点や返却のときに使う、解答用紙に模範解答を書き込んだ紙（模範解答つき解答用紙）がまだない。

## What Changes

- 紙のタブの並びに「（開いている紙の名前）をPDFで出力」のボタンを置く。押すと、開いている紙だけの印刷の画面を開く。送信先で「PDFに保存」を選ぶと PDF になる（ブラウザの印刷を使う。サーバーでは PDF を作らない）
- 印刷の画面を開いている間は、ページの題を「年度　テストの名前　国語　紙の名前」にして、保存するときのファイル名の既定にする。ボタンを使わずにブラウザの印刷を開いたときも同じにする
- 紙は一つずつ別の PDF にする。三枚をまとめた一つの PDF は作らない
- 「模範解答つき解答用紙」のタブを、解答用紙と模範解答・採点基準の間に足す。解答用紙と同じ割り付けの紙に、模範解答を赤字で書き込み、題の列の末尾に「模範解答」と入れる
  - マス目の欄には一マスに一字ずつ、マス目でない欄には縦書きで欄に収まる大きさで書く
  - 作文は模範解答を持たないので、欄を空けておく
  - 模範解答がマス目の数より長いときは、入る分だけ書き、入りきらないことを会話に出す
- 模範解答・採点基準の表も、同じボタンで PDF にできる
- 模範解答・採点基準の表は二ページ以上に続くので、表のページにだけ余白をとる
- 印刷を始めると狭い画面の判定が紙の幅で当てはまり、紙面の列が消えて PDF が白紙になっていたのを直す（これまでの印刷にもあった不具合）

## Capabilities

### New Capabilities
- `pdf-export`: 開いている紙を、ブラウザの印刷から紙ごとに PDF として出力する。保存するときのファイル名の既定を決める

### Modified Capabilities
- `answer-sheet`: 紙のタブに「模範解答つき解答用紙」を足す。模範解答を書き込んだ解答用紙を描き、マス目に入りきらない模範解答を知らせる

## Impact

- 変更: `src/App.tsx`（タブを四つにする、PDF で出力するボタン、印刷の間のページの題、入りきらない模範解答の知らせ、狭い画面の判定を画面のときだけにする）、`src/sheet/layout.ts`（欄に書き込む答えを割り付けで持たせる）、`src/sheet/AnswerSheet.tsx`（答えを書き込んで描く、題に「模範解答」）、`src/sheet/sheet.css`（答えの文字、表のページの余白）、`src/index.css`（ボタンと案内）
- テスト: `src/sheet/layout.test.ts`（欄ごとの答えと入りきらない答え）、`e2e/sheets.spec.ts` か新しい `e2e/pdf.spec.ts`（ボタン・ページの題・印刷で出るページの数と大きさ）
- 問題用紙と解答用紙の割り付け・見た目は変えない。印刷の CSS（`@page` の B4 横）はそのまま使い、表のページの余白（`@page key`）だけを足す
- 依存は増やさない。サーバー側（`api/`）も変えない
- 文書: `docs/モックとの突き合わせ.md` の解答用紙・模範解答の節に、模範解答つき解答用紙と PDF の出力を「作った」として足す
