## Context

紙面（問題用紙）は、テストをブロック（表紙・大問の見出しと本文・小問・結び）に分け、画面の外で各ブロックの幅を測ってページに詰めている。ブロックの組み立てと幅の測り直しは、テスト・配点の枠・紙面の操作が変わったときだけ行い、選んでいる印・変わった印・要確認の印・確定していない小問の薄い色は、ページを描くときにクラスを足すだけで付けている。AI が作っている大問と付け直している大問は、画面全体の状態としてすでに持っていて、会話の表示と大問の一覧の状態に使っている。

## Goals / Non-Goals

**Goals:**
- 作っている間の印を、既存の印と同じく、割り付けに触れずに付ける
- 動きを減らす設定の端末でも、印刷でも、正しく見える（または消える）ようにする

**Non-Goals:**
- 作っている途中の小問を少しずつ見せる（AI の返答を流しながら描く）ことはしない
- 解答用紙・模範解答つき解答用紙・模範解答と採点基準の表には印を付けない（作っている間はまだ前の中身が描かれていて、変わる箇所は問題用紙で示せば足りる）
- AI の案を出す小問の足し方の画面（ダイアログ）は変えない。紙面を覆っていて、中にすでに待ちの表示がある

## Decisions

- **印はページを描くときにクラスで付け、ブロックの組み立てには入れない。** 作っている大問・付け直している大問を紙面に渡し、ページを描くところで、そのブロックに印のクラスと `aria-busy` を足す。ブロックの組み立てに入れると、作り始めと作り終わりのたびに幅を測り直し、その間は割り付けがなくなって紙面が一瞬消える。
  - 代わりの案: 小問の場所に「作っています」の仮のブロックを足す。どこに小問が入るかは分かりやすいが、幅を測るブロックが増えて割り付けが変わり、印刷で消すと空きが残るのでやめた
- **印はブロックに重ねる疑似要素で描く。** 余白・枠・幅を変えるものは使わない（割り付けの幅が変わるため）。重ねる層は、紙面の操作のボタンと要確認の印より下にし、クリックは下に通す（作っている間も小問のすき間の「＋ 小問を追加」などの操作は今までどおり押せる）。
- **光の帯は右から左へ流す。** 縦書きの紙面は右から左へ読み進めるので、その向きに合わせる。帯の位置はブロックごとの幅に対する割合で動かすので、幅の違うブロックどうしで帯はそろわない。そろえるには紙面全体で位置を合わせる仕組みが要り、見え方の得に比べて大きいので、ブロックごとの動きでよしとした。
- **バッジは縦書きで、見出しのブロックの右下に置く。** 横書きにすると本文の枠の端の文字にかぶる。見出しのブロックの右端の列は指示文の行で、指示文は列の途中で終わるので、その下の空いたところに縦書きで置けば本文にかぶらない。紙面の操作のボタン（右上に縦書きで並ぶ）とも向きがそろう。
- **動きを減らす設定は、既存の一括の止め方に任せる。** 全体の CSS ですでに、動きを減らす設定の端末ではアニメーションを止めている。止まったときに光の帯は見えない位置にあり、薄い青とバッジが残るので、印の分だけの特別な扱いは足さない。

## Risks / Trade-offs

- [指示文が長く、見出しの右端の列の下まで埋まっている] → バッジが指示文の末尾の字にかぶる。作っている間だけの表示で、作り終えると消えるので、そのままにする
- [ページの縮小率が小さい画面ではバッジの字が小さい] → バッジの字は紙面の操作のボタンより一回り大きくし、縮小しても読めるようにした
- [作っている間に先生が紙面の小問を直す] → 印は操作を妨げないので直せる。作り終えたときの当てはめ方は今までどおり（作った大問で置き換える）

## 確認してほしい判断

- 紙面の印を付けるのは、大問を作っている間と、ルビ・返り点・送り仮名を付け直している間だけにした。AI が小問と本文の食い違いを確かめている間と、会話で頼んで AI の返答を待っている間は、紙面に印を付けない（前者は作るのではなく確かめる処理で、後者は返答が来るまでどこが変わるか分からないため）
- 印の色は、画面の操作に使っている青を中心に、少しだけ紫を混ぜた。派手にはしない
- バッジの文言は「✦ AI が作っています」と「AI が付け直しています」にした
- 作っている間も、その大問の小問を直す・消す・並べ替えるなどの紙面の操作はできるままにした
