## Context

動機は proposal.md、振る舞いは specs を参照。

いまの作り:
- 右端の欄（`.sheet-side`、CSS の幅 34mm・割り付け上の `SHEET.side` 36mm）は、題の列と、名前の欄・合計の欄を縦に積んだ列（幅 16mm）を横に並べている。合計の欄は名前の列の幅しかない
- 名前の欄は縦書きの flex で `space-around` にしており、学年・組・番・氏名が欄の長さに均等に散る。横方向は stretch のままなので、縦書きの文字が行の先頭（右端）に寄る
- 見出し（`.sheet-head`）はすべて灰色。小計は一行目を灰色、二行目を白にしていて、観点ではなく位置で色が決まる。小計は下に詰めて積むので、知・技だけの大問は知・技の行がいちばん下の段に来る
- 確定していない大問は `.sheet-prop` を付け、画面だけ枠を破線にしている。そのために `AnswerSheet` は `confirmed` を受け取る
- 参照の解答用紙（docs/reference/サンプル解答用紙.pdf）は、知識・技能の小問の、答えの欄のすぐ上の見出しを網掛けにしている。項目を持つ小問の問の見出しは白。小計は網掛けの段（知・技）が上、白の段（思・判・表）が下

## Goals / Non-Goals

**Goals:**
- 網掛けを観点だけで決め、見出し・小計・合計で同じ意味にそろえる
- 右端の欄の組み方を変え、名前と点数を書く余白をとる

**Non-Goals:**
- 割り付け（マスの大きさ・列への積み方）と `SHEET.side` を変えること。変えると収まるマスの大きさが変わり、割り付けのテストとサンプルの見た目が動く
- 問題用紙の確定前の見せ方を変えること
- マス目の中の区切りの点線を変えること

## Decisions

### 1. 網掛けの印は割り付けで決める
- `Unit` に `shaded`（見出しを網掛けにするか）を足し、`layoutSection` が見出しを積むときに決める。項目・空欄の見出しは小問が知識・技能なら網掛け。問の見出しは、その欄に項目・空欄の見出しがなく、小問が知識・技能なら網掛け。
- 割り付けは見出しと欄の関係（どの見出しが欄のすぐ上か）をすでに知っているので、描く側で小問をたどり直さずに済む。単体テストで網掛けの位置を確かめられる。
- 別案（描く側で観点のクラスを付け、CSS で網掛けを決める）: 「項目があれば問の見出しは白」を描く側でもう一度判断することになり、割り付けと二か所に知識が散る。

### 2. 小計は観点ごとに決まった段に置く
- 小計の欄は二段ぶんの場所をとり、知・技は上の段、思・判・表は下の段に置く。ない観点の段は描かない。網掛けは観点で付ける（知・技が網掛け）。
- 割り付けの段の数は、いまも小計の二段ぶんを除いて計算しているので変わらない。

### 3. 右端の欄は「上に題と名前、下に合計」の二段にする
- 右端の欄を縦に二つに分け、上は題の列（右）と名前の欄（左、幅 12mm）を横に並べ、下は二つの幅をあわせた合計の欄を置く。題の列の幅は文字に合わせた決まった幅にし、題と名前の欄の組を右に寄せる。`SHEET.side` は変えないので、名前の欄と解答欄の間には、いまと同じくらいのすき間が残る。
- 合計の欄は三行、各行 15mm ほどの高さにし、観点の名前を左上に小さく、満点の内訳（／27 など）を右下に置く。真ん中が点数を書く余白になる。
- 名前の欄は `space-around` をやめ、上から学年、すき間（組の数字）、組、すき間（番の数字）、番、氏名と決まった間隔で並べる。氏名の下は欄の終わりまで空ける。文字は欄の幅の中央に置く。
- 別案（合計の欄を名前の欄の幅のまま、行だけ高くする）: 幅 12mm では「思・判・表」の名前と点数が並ばず、書き込む余白が狭い。参照の解答用紙も合計の欄は題の下まで広げている。

### 4. 確定前の破線をやめ、`confirmed` を解答用紙に渡さない
- `.sheet-prop` とその CSS をなくし、`AnswerSheet` の `confirmed` 引数と `App.tsx` からの受け渡しを消す。確定したかどうかは問題用紙と会話で分かる。
- e2e の「解答用紙は確定していない大問が破線」の確認は消し、テスト名も直す。

### 5. 網掛けは印刷でも出す
- 網掛けにする要素（見出し・小計・合計の行）に `print-color-adjust: exact` を付ける。付けないと、ブラウザの既定で印刷のときに背景色が落ちる。

## Risks / Trade-offs

- [題の列が合計の欄のぶん短くなり、長いテストの名前が入りきらない] → 題は一行で折り返さない。いまの文字の大きさで三十字ほどまでは入る。入らない名前が出てきたら、文字を小さくするか二行にする
- [解答用紙だけを見ると、どの大問が未確定か分からなくなる] → 確定の状態は問題用紙の大問の操作と会話で見る。解答用紙は配る紙としての見た目を優先する
- [網掛けの意味の凡例がない] → 小計と合計の「知・技」の行を網掛けにして、凡例を兼ねる

## 確認してほしい判断

- 網掛けは知識・技能の小問に付け、思考・判断・表現は白にする（逆にはしない）
- 網掛けを付けるのは、答えの欄のすぐ上の見出しだけにする。項目（①②…）を持つ小問では、項目の見出しが網掛けになり、問の見出しは白のまま
- 確定していない大問も、解答用紙では実線で描く（解答用紙の上では確定したかどうかが見えなくなる）
- マス目の中の区切りの点線は残す（枠線だけを実線にする）
- 名前の欄の幅は 12mm にし、合計の欄は題の列と名前の欄をあわせた幅にする
