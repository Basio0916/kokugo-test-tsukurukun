## MODIFIED Requirements

### Requirement: テストは大問の並びを持つ
テストは大問を順番付きで持つ SHALL。大問は、種類（漢字・文法・文学的文章・説明的文章・古文・漢文・作文）、指示文、小問の並びを持つ。文学的文章・説明的文章・古文・漢文の大問は本文を持ち、漢字・文法・作文の大問は本文を持たない。ただし、文学的文章・説明的文章・古文の大問は、本文を貼る前の状態として、本文も小問も持たないことができる（小問だけを持つことはできない）。作文の大問は、小問の代わりに条件の並びを持つ一つの作文の問として表す。

#### Scenario: 文章を扱う大問
- **WHEN** 種類が文学的文章の大問を作る
- **THEN** その大問は本文と出典を持てる

#### Scenario: 本文を持たない大問
- **WHEN** 種類が漢字の大問を作る
- **THEN** その大問は本文を持たず、小問だけを持つ

#### Scenario: 本文を貼る前の大問
- **WHEN** 種類が文学的文章で、本文も小問も持たない大問を作る
- **THEN** その大問は正しいデータとして扱われる

#### Scenario: 本文がないのに小問がある
- **WHEN** 種類が文学的文章で、本文を持たずに小問を持つ大問を作る
- **THEN** その大問は不正なデータとして扱われる

### Requirement: 本文は傍線部・ルビ・返り点を文字の位置に結び付けて持つ
本文は文字列として持ち、傍線部・ルビ・漢文の返り点と送り仮名を、本文中の文字の位置に結び付けて持つ SHALL。傍線部はそれぞれ識別子を持つ。漢文でない本文は、段落の区切りを持てる。傍線部は段落をまたがない。漢文の本文は句（行）ごとに持ち、各文字に返り点と送り仮名を付けられる。

#### Scenario: 傍線部を持つ本文
- **WHEN** 「メロスは激怒した。」の「激怒した」に傍線部を付ける
- **THEN** 本文の文字列はそのまま保たれ、傍線部は「激怒した」の範囲を指す識別子として保持される

#### Scenario: 漢文の返り点と送り仮名
- **WHEN** 漢詩の句「春眠不覚暁」の「不」にレ点、「覚」に送り仮名「エ」とレ点、「暁」に送り仮名「ヲ」を付ける
- **THEN** それぞれの文字に返り点と送り仮名が結び付いて保持される

#### Scenario: 段落の区切り
- **WHEN** 二つの段落からなる本文を持つ
- **THEN** 段落の区切りの位置が保たれ、本文の文字列は変わらない
