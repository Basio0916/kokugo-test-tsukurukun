## Purpose

問題用紙と同じテストのデータから、採点に使う模範解答・採点基準の表を作る。正答の記号や番号、配点、観点はシステムが導き、問題用紙を直すとすぐにそろって変わる。

## ADDED Requirements

### Requirement: 模範解答・採点基準の表
「模範解答・採点基準」のタブで、大問ごとのまとまり（【一】と大問の名前）の下に、小問ごとの行を並べた表を描く SHALL。列は、設問（問一）、正答・模範解答、配点、観点・指導事項、採点基準とする。

- 正答・模範解答: 記号選択は正答の記号（ア〜）。項目のある小問は、項目の見出し（①…。傍線部を指す項目は傍線部の番号）と答えを並べる（記号選択の項目は記号）。それ以外は答え（模範解答）
- 配点: 項目ごとの配点の小問は「各二点」のように書き、それ以外は「四点」のように書く
- 観点・指導事項: 知識・技能か思考・判断・表現かと、指導事項の記号
- 採点基準: 採点の観点があれば並べる。なければ、記号選択は「記号が合っていれば正答」、それ以外は「答えが合っていれば正答」とする

表の最後に、観点別の合計と合計・満点を置く。本文を貼る前の大問は、「本文を貼ると、小問と一緒に作られます」と出す。

#### Scenario: 記号選択と記述
- **WHEN** サンプルのテストで模範解答・採点基準のタブを開く
- **THEN** 【三】問二の行に正答「イ」・配点「四点」・「知識・技能 (1)エ」・「記号が合っていれば正答」が、問三の行に模範解答と三つの採点の観点が出る

#### Scenario: 傍線部を指す項目
- **WHEN** 古文の大問に、傍線部②と③を指す仮名遣いの項目がある
- **THEN** 正答・模範解答は「② ゆりすえ　③ ただよえ」、配点は「各二点」になる

#### Scenario: 配点を変える
- **WHEN** 【三】問二の配点を一点上げてから模範解答・採点基準を開く
- **THEN** 問二の配点が「五点」になり、観点別の合計と合計も変わる
