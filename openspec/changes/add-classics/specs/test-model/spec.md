## MODIFIED Requirements

### Requirement: テストは大問の並びを持つ
テストは大問を順番付きで持つ SHALL。大問は、種類（漢字・文法・文学的文章・説明的文章・古文・漢文・作文）、指示文、小問の並びを持ち、教材の大問は教材名（単元データの教材名）を持てる。文学的文章・説明的文章・古文・漢文の大問は本文を持ち、漢字・文法・作文の大問は本文を持たない。ただし、文学的文章・説明的文章・古文・漢文の大問は、本文を貼る前の状態として、本文も小問も持たないことができる（小問だけを持つことはできない）。作文の大問は、小問の代わりに条件の並びを持つ一つの作文の問として表す。

#### Scenario: 文章を扱う大問
- **WHEN** 種類が文学的文章の大問を作る
- **THEN** その大問は本文と出典を持てる

#### Scenario: 本文を持たない大問
- **WHEN** 種類が漢字の大問を作る
- **THEN** その大問は本文を持たず、小問だけを持つ

#### Scenario: 本文を貼る前の大問
- **WHEN** 種類が文学的文章で、本文も小問も持たない大問を作る
- **THEN** その大問は正しいデータとして扱われる

#### Scenario: 本文がないのに小問がある
- **WHEN** 種類が文学的文章で、本文を持たずに小問を持つ大問を作る
- **THEN** その大問は不正なデータとして扱われる

#### Scenario: 白文を貼る前の漢文の大問
- **WHEN** 種類が漢文で、教材名「漢詩の風景」を持ち、本文も小問も持たない大問を作る
- **THEN** その大問は正しいデータとして扱われる
